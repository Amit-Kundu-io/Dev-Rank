# DevRank 🚀

DevRank is a modern GitHub Explorer app built using Compose Multiplatform.  
It provides a clean UI and structured state management using MVI architecture.

---

## ✨ Features

- Modern UI built with Jetpack Compose
- Cross-platform UI using Compose Multiplatform (CMP)
- State management using MVI architecture
- REST API integration using Ktor
- Handles loading, success, and error states
- Clean and scalable project structure

---

## 🛠 Tech Stack

- Kotlin
- Compose Multiplatform (CMP)
- Ktor Client
- MVI Architecture
